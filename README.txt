EXAM DISPLAY - PHASE 1 + PHASE 2

1) Upload these files to GitHub repository:
   index.html
   app.js
   admin.html
   admin.js
   style.css
   supabase.js

2) Run schema.sql in Supabase > SQL Editor.

3) Supabase Storage:
   Bucket name: exam-images
   It should be PUBLIC.

4) Create an admin account:
   Supabase > Authentication > Users > Add user

5) Open:
   index.html = display
   admin.html = admin

Features:
- Supabase database
- Admin login
- Add/delete exam schedules
- Realtime display updates
- Clock position: left/center/right
- Clock size
- Image size/position
- Show/hide date, clock, schedule, image
- Announcement
- Fullscreen
- Next-exam status

# Exam Display

เวอร์ชันทดสอบสำหรับระบบตารางสอบแบบรูปภาพ

## ทดลองทันที
1. เปิด `admin.html`
2. เลือกรูปตารางสอบ
3. ปรับขนาดนาฬิกา/รูป
4. กดบันทึกและเผยแพร่
5. เปิด `index.html`

## หมายเหตุ
เวอร์ชันนี้เก็บรูปและค่าตั้งค่าใน browser (`localStorage`) เพื่อให้ทดสอบ UI ได้ทันที
ขั้นต่อไปให้เชื่อม Supabase Storage + Database เพื่อให้ Admin เครื่องหนึ่งอัปโหลดแล้วจออื่นเห็นรูปเดียวกันแบบออนไลน์
